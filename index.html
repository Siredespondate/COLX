SILENT ZONE

RESTRICTED / SILVERAT SPECIAL ARCHIVE / INTERNAL NODE

정적구역의 존재·구조·개체 기록은 공개 국제 아카이브와 분리된다. 이 문서는 단일 HTML 내부에 포함된 제한 기록층이며, 접근 인증을 통과한 세션에서만 열람할 수 있다.

정적구역의 성격

실베라트 공화국 내부에 존재하는 특수 제한구역. 외부 환경과 직접적인 연결을 최소화하고, 내부 개체의 생태적 안정성과 관찰자료의 장기 보존을 우선한다.

공개 기록과의 차이

일반 국가문서에는 존재 여부조차 명확히 기술되지 않으며, 공개된 생태연구시설과 별개의 분류체계를 가진다. 내부 자료는 일반 검색 색인에서 제외된다.

관리 원칙

  • 외부 환경 변화의 직접 유입 최소화
  • 개체의 생활 리듬과 생태 안정성 우선
  • 관찰과 생활을 동일 공간으로 취급하지 않음
  • 급격한 상태저하 시 생태회복실 사용

기록 항목

  • 광량
  • 오염도
  • 수분도
  • 향 농도
  • 주변 생명력
  • 습도는 고정값으로 취급

10개 개체

꽃을 기반으로 한 식물 유래 비인간 지능 개체 10명. 각 개체는 좌안의 꽃을 주요 식별요소로 가지며, 서로 다른 성향과 역할을 보인다.

  • 해청 — 청색 / 보호자적 성향
  • 적랑 — 적색 / 활발·호기심
  • 옥연 — 민트 / 원칙·안정성
  • 자령 — 보라 / 관찰자·개인주의
  • 도월 — 분홍 / 거리감 있는 보호자
  • 유록 — 녹색 / 안정·자연 친화
  • 운서 — 주황 / 돌봄·행동성
  • 단야 — 백색 / 연령에 비해 성숙함을 요구
  • 설흔 — 흑색 / 강한 호기심과 친화성
  • 침운 — 황색 / 비판적 현실주의

공통 생태적 특징

  • 식물과 유사한 방식으로 수분을 이용
  • 시설 내부의 자연광을 생활 주기로 활용
  • 일반적인 인간 생활공간과 다른 생리적 요구
  • 개체별 꽃의 형태·색·상태가 관찰 지표로 활용됨

A구역 · 봄

새싹·개화·연한 녹음이 중심인 환경. 변화량이 큰 계절로 분류되어 식생의 초기 성장과 개화 상태를 관찰하기 좋다.

B구역 · 여름

높은 광량과 밀도 높은 녹음이 특징. 수분 공급과 식생 밀도 관리가 주요 환경 변수로 기록된다.

C구역 · 가을

낙엽과 색 변화가 존재하는 환경. 식물의 생장주기 변화와 향 농도의 계절적 차이를 비교한다.

D구역 · 겨울

저온·저광량 환경을 재현한 구역. 개체의 안정성과 회복 상태를 장기적으로 관찰한다.

중앙생태관찰홀

A~D 구역의 상태를 한눈에 확인할 수 있는 중심 공간. 환경값과 개체 상태를 비교·기록하기 위한 관찰 중심지다.

생태회복실

연구실이 아니라 갑작스럽게 컨디션이 저하된 개체가 안정을 되찾기 위한 회복 전용 공간. 회복용 포드를 사용한다.

생활구역

창문이 없으며 외부 풍경이 직접 유입되지 않는다. 자연광은 시설 시스템을 통해 자동 공급된다.

환경관리 계통

광량·수분·공기질·향 농도 등을 개별적으로 관리한다. 습도는 일반적인 변동 지표가 아니라 고정된 관리값으로 취급된다.

식생활

일반적인 인간의 식사와 다른 방식으로 생활한다. 물을 주요 공급원으로 사용하며 식물적 생리와 연관된 생활주기를 가진다.

일상

  • 자연광 공급에 따른 생활 리듬
  • 계절환경에 따른 공간 이동·활동
  • 개체별 꽃 상태 관찰
  • 공용 관찰공간과 개인적 생활영역의 구분

외부 인식

외부 세계를 직접 볼 수 있는 창구가 없도록 설계되어 있다. 내부에서 외부의 존재를 추측할 수 있는 단서 또한 제한된다.

생활환경 기록

광량, 오염도, 수분도, 향 농도, 주변 생명력이 주요 기록값이며, 급격한 변화는 별도 상태 이벤트로 분류한다.
